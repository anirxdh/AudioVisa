**Part A: Write 30 hero scenes directly into data/scenes.json**

Hand-write 30 high-quality hero scenes. These are the flagship scenes used for demo and pre-generated audio. Each must have a distinctive "acoustic fingerprint" with layered sounds that make the location and era guessable.

Distribution targets for hero scenes:
- Difficulty: ~10 easy, ~12 medium, ~8 hard
- Categories: At least 3 scenes per category across the 30 (some categories may have 4-5)
- Geographic diversity: Cover all 6 continents, mix of well-known and interesting locations
- Era diversity: Range from 1800s to 2020s

Quality criteria per hero scene (from research — Acoustic Fingerprint Theory):
- **Biome layer:** Environmental baseline (tropical rain, arctic wind, temperate city)
- **Soundmark layer:** Iconic recognizable sounds (Big Ben chimes, muezzin call, steam locomotive)
- **Cultural-linguistic layer:** Language, accent, music genre markers
- **Era/technology layer:** Era-specific sounds (horse hooves vs car engines, vinyl vs digital)
- **Microlocal layer:** Hyper-specific details (specific market vendor calls, regional bird species)

Each hero scene MUST have:
- `id`: kebab-case, descriptive (e.g., "marrakech-souk-spice-market-1970s")
- `location`: Specific place name
- `country`, `continent`, `era`: Accurate
- `difficulty`: Calibrated — easy = globally iconic sounds, hard = specialist knowledge but still guessable
- `description`: 2-3 sentences of vivid atmospheric prose
- `sounds`: 4-6 specific, descriptive sounds (not generic like "market sounds")
- `sfx_prompts`: 2-3 detailed ElevenLabs prompts, each 30+ characters, describing specific audio scenes
- `music_prompt`: 1 detailed prompt for era/region-appropriate instrumental music
- `category`: One of the 7 valid categories

Example hero scenes to include (mix of these and other creative choices):
- Tokyo fish market 1990s (markets, medium)
- Marrakech souk 1970s (markets, medium)
- London during the Blitz 1940s (historical, hard)
- Manhattan yellow cab ride 2010s (transport, easy)
- Amazon rainforest dawn (nature, medium)
- Mumbai railway station 2000s (transport, medium)
- Venetian gondola ride 1960s (transport, medium)
- Berlin Wall fall 1989 (historical, hard)
- Rio Carnival 2010s (festivals, easy)
- Serengeti savanna dawn (nature, medium)

Write all 30 into `data/scenes.json` as `{ "scenes": [...30 scenes...] }`.

**Part B: Create scripts/generate-scenes.ts**

Create the AI batch generation script using OpenAI Structured Outputs + Zod:

1. Define a Zod schema matching the Scene interface exactly (same fields, same constraints: sounds array 4-6 items, sfx_prompts 2-3 items, sfx_prompt min 30 chars, id regex /^[a-z0-9-]+$/)

2. Read existing scenes from data/scenes.json to:
   - Track already-used locations (pass to prompts to avoid duplicates)
   - Know the current count

3. Generate scenes in batches of 10 per API call using `client.beta.chat.completions.parse()` with `zodResponseFormat`

4. System prompt should include:
   - Acoustic Fingerprint Theory layers (biome, soundmark, cultural-linguistic, era/technology, microlocal)
   - ElevenLabs SFX prompt guidelines: be specific, descriptive, 30+ chars, describe the full audio scene not just a single word
   - Difficulty calibration rules: easy = globally iconic, medium = regionally recognizable, hard = specialist but guessable
   - Constraint: each sfx_prompt must be a rich, detailed description suitable for ElevenLabs Sound Effects API

5. Generate per category with explicit difficulty distribution targets:
   - markets: 25 scenes (8 easy, 12 medium, 5 hard)
   - historical: 25 scenes (5 easy, 13 medium, 7 hard)
   - city_streets: 25 scenes (8 easy, 12 medium, 5 hard)
   - nature: 25 scenes (10 easy, 10 medium, 5 hard)
   - industrial: 20 scenes (5 easy, 10 medium, 5 hard)
   - festivals: 25 scenes (8 easy, 12 medium, 5 hard)
   - transport: 25 scenes (8 easy, 12 medium, 5 hard)
   Total: ~170 AI scenes

6. Write incrementally after each batch (not at the end) to avoid losing progress on API errors. Read existing, append, write back.

7. Include a deduplication check: skip scenes with IDs already in the file.

8. Use model `gpt-4o-mini` for cost efficiency (~$0.10 total for 170 scenes).

9. Add console logging: batch number, category, count generated, running total.

The script should be runnable via: `OPENAI_API_KEY=sk-... npx tsx scripts/generate-scenes.ts`
